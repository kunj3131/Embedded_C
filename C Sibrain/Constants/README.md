# Constant Keyword

const int a : can not provide any value ex. a=b or a=10
  but we can perform arithmetic operation and we need to store in another variable.
   arithmetic, logical, bitwise etc.

## Pointer

int const *a or const int *a : variable pointer to a constant integer

int *const a : constant pointer to an integer

const int *const a : constant pointer to a constant integer
